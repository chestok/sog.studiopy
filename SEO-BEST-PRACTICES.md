## 📱 Optimización Mobile (Core Web Vitals)

### Métricas a Monitorear

1. **Largest Contentful Paint (LCP)**
   - Meta: < 2.5 segundos
   - Herramienta: Google PageSpeed Insights

2. **First Input Delay (FID)**
   - Meta: < 100 milisegundos
   - Optimizar: Interactividad JS

3. **Cumulative Layout Shift (CLS)**
   - Meta: < 0.1
   - Optimizar: Estabilidad visual

### Optimizaciones Técnicas Recomendadas

```html
<!-- Image Optimization -->
<img src="image.jpg" alt="descripción" loading="lazy">

<!-- WebP Format -->
<picture>
  <source srcset="image.webp" type="image/webp">
  <img src="image.jpg" alt="descripción">
</picture>

<!-- Font Loading Optimization -->
<link rel="preload" href="fonts.css" as="style">
```

## ⚠️ Errores Comunes a Evitar

### ❌ NO Hacer

1. **Keyword Stuffing**
   - No repetir la palabra clave > 2%
   - Mantener densidad natural

2. **Contenido Duplicado**
   - Usar canonical tags
   - Crear contenido único

3. **Actualizar Frecuentemente**
   - Solo si hay mejoras reales
   - Cambios frecuentes confunden a Google

4. **Comprar Backlinks**
   - Violación de políticas de Google
   - Resultado en penalizaciones

5. **Ignorar Mobile**
   - Google es mobile-first
   - Obligatorio optimizar para mobile

6. **No Validar HTML**
   - Errores de código
   - Afecta rastreo

7. **Ignorar Analytics**
   - Datos = decisiones
   - Revisar regularmente
